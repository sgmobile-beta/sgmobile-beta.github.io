SGMobile Beta 1.0

An unofficial mobile adaptation of Sid Meier's SimGolf. Classic keeps the
original game rules. Enhanced lets you choose optional features per career.
This project is independent of the original game's creators and rights holders.

INSTALL ON IPHONE
Open https://sgmobile-beta.github.io/ in Safari. Use Share > Add to Home Screen
to install the SGMobile Beta icon. Use Choose Files to select your own original
disc image and matching game executable. The game processes these files on
your device. A disc image alone cannot start the game.

The tested input pair is the original rerelease disc image and the v1.02
executable with SHA-256:
21c98fa5ffa0a552543a09f6ca0a58eed4b666d2646f02ea0a93cf8d53d80ca1
The filename alone does not establish compatibility. Report the original
edition and version if the installer rejects a pair. Original files are
user-supplied. Safari and iOS versions must support WebAssembly JSPI and
private browser storage. The app uses original local files for the opening
movie. ZIP, 7z and RAR support has less phone test coverage than ISO plus EXE.

MOVING A SAVE TO BETA
Beta has a different website, Home Screen identity and browser storage.
Install the original files in Beta even if you already installed them in
Alpha. Export copies from the old app before opening the new one.

* Use a native .sve for an original Classic career. The file contains the
  native game state. Choose Classic when prompted. A separate Enhanced copy
  is available if you want to enable optional features.
* Use Portable Backup (.sgsave) for an Enhanced career. The bundle carries
  native game bytes plus the associated edition, revision, feature settings
  and histories. Use an app that supports Enhanced to reopen this backup.

Open Backup & Transfer Files from the play options or the in-game System menu.
Import the copy under a distinct name if there is a conflict. Verify the course
and edition in Saved Course Preview before entering. Keep your original
exports in Files and retain the older app for its earlier careers.

SAVES, OFFLINE USE AND UPDATES
Manual saves, native autosaves and Backup History use this website's storage.
Backup History has a retention limit. Export important .sve and .sgsave
copies outside the app, especially before an update or restoring an older
revision. Restoring an older backup makes a separate copy. Clearing browser
site data can remove installed files and saves.

When the app says its resources are stored, close the Home Screen app and
reopen it with the network disconnected to test offline play. For an update,
check from Welcome or the title screen. Save, close all Beta windows, reopen,
and verify the new build. Run one game window per address when saving.
Device storage pressure and browser eviction can affect offline availability.

USAGE AND SUPPORT
The public Beta measures one session per app opening that reaches a playable
course and counts only active, visible course time. Welcome, loading, paused,
hidden and suspended intervals do not add playtime. Usage sends a random batch
ID, batch start time, build, and session and time increments. Offline usage
can wait on the device for retry. Original game files, saves and career data
stay in browser storage. Ko-fi and Discord are optional external services.
The donation card can show approved public donations and a last confirmed
snapshot when offline.

REPORTING ISSUES
Include the Beta version and build, phone and iOS version, browser or Home
Screen, orientation, and the steps to reproduce. Keep private saves,
credentials and original game files out of public reports. Keep an export
before attempting recovery.
